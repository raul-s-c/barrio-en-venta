# Barrio en Venta - ayuda de juego

## En tu turno

Haz dos acciones diferentes:

1. Explorar: revela frontera; si sale vivienda libre, puedes reservarla gratis.
2. Reservar/disputar: coloca prioridad. Para quitar la rival, descarta carta; el rival roba carta.
3. Vender: vivienda revelada + cliente compatible + sin prioridad rival.
4. Captar: toma publico o roba dos y conserva uno.
5. Agencia: roba dos y conserva una.
6. Ayuntamiento: mira dos losetas, renueva cliente, tramita Litigio o recupera prioridad.

## Venta

```text
Base + casilla de linea + cliente
+ Comercio/Reforma urbana
- incidencias
+ carta propia - Reaccion rival
```

Maximo una carta propia y una Reaccion. Minimo 0 puntos.

## Fin de ronda

- Quien va perdiendo revela una frontera; en empate, quien no tuvo Primera visita.
- Avanza ronda.
- Cambia Primera visita.

## Cierre

Quinta venta en una linea: +5, termina el turno y el rival juega un ultimo turno. Si tambien completa linea: +2.

## Final

- Objetivo.
- +2 por vender al menos una de cada categoria.
- Mayorias: Lujosa +4, Media +3, Barata +2. Empate: 0.
